# 3DPrint — клиентский портал

Адаптивное React-приложение на TypeScript для оформления заказов на 3D-печать. Интерфейс повторяет тёмную тему исходного макета и включает клиентский кабинет и рабочее место менеджера.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```powershell
npm install
npm run dev
```

Для production-сборки и локального просмотра:

```powershell
npm run build
npm run preview
```

## Функциональность

- адаптивная навигация с мобильным меню и переключением светлой/тёмной темы;
- загрузка и drag-and-drop моделей STL, OBJ, 3MF и PLY с проверкой размера до 100 МБ;
- выбор материала, совместимой технологии, цвета, слоя, заполнения и постобработки;
- асинхронный калькулятор стоимости и сроков;
- история заказов, фильтрация статусов и повтор заказа;
- АРМ менеджера с очередью, фильтром, изменением статусов и имитацией проверки оборудования;
- выделенный mock API в `src/services/api.ts` с типизированными сущностями и задержками, готовый к замене REST-запросами.

Все данные хранятся локально в браузере; загрузка файлов на сервер и онлайн-оплата не выполняются. Для production необходимо заменить mock API на реальные REST endpoints.

## Структура приложения

- `src/App.tsx` — страницы кабинета, менеджера, таблица заказов и UI;
- `src/components/ui.tsx` — переиспользуемые Button, Card, Badge, Select и Spinner;
- `src/context/OrderContext.tsx` — состояние конфигуратора, цены, заказов и уведомлений;
- `src/services/api.ts` — mock API, материалы и демонстрационные заказы;
- `src/types.ts` — типы заказов, материалов, технологий и результатов валидации;
- `src/index.css` — Tailwind CSS, дизайн-токены и адаптивные стили.

Файлы исходного дизайн-макета (`Main.dc.html`, `support.js` и `vendor/`) оставлены в корне как справочные материалы; Vite-приложение их не загружает.
