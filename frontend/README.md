# 3DPrint Frontend — Временный клиентский портал

> **Статус:** временный UI для отладки и тестирования клиентского портала (зона ответственности А. Г. Видермана) поверх реального API (`orders`, `pricing`, `messaging`, `notifications`, `catalog`).
> Экраны входа/регистрации используют временный адаптер `/api/auth/*` до слияния модуля `users`.
> АРМ менеджера (зона ответственности А. Д. Колотухина) выведен в заглушку `/manager`.

## Запуск и проверка
- `npm run dev` — режим разработки (прокси `/api` -> `VITE_PROXY_TARGET`, по умолчанию `http://localhost:8000`)
- `npm run build` — проверка типов TypeScript + сборка Vite
- `npm test` — тесты Vitest
